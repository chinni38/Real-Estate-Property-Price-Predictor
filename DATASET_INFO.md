# Dataset Information

`property_data.csv` is a clean synthetic structured housing dataset created for this Week 7 milestone.

- Rows: 6,000
- Target: `price`
- Input features: 9
- Format: CSV
- Random seed: 42
- No missing values
- No external download required

The dataset is designed to support the required 80/20 train-test split, dual-regressor comparison, and custom property inference demo.
